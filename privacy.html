Privacy policy

Last updated 16 November 2026.

Nathan mail sorter is a private tool used only by its owner, on the owner's own Gmail account. This policy describes how it handles that data.

Data accessed

With the owner's permission (the Gmail "modify" scope), the app reads email in the owner's mailbox: headers, labels and message content.

How it is used

Only to decide which label each email belongs under, and to apply that label. Nothing is used for advertising, sold, or shared with anyone else.

Storage

The app keeps a record of each message's identifier, sender, subject, date and the sorting decision made, so every change can be audited and undone. It does not keep copies of message bodies. Records are held on the owner's private servers.

Automated processing

To classify mail, message content may be sent to AI model providers acting on the owner's behalf. These providers process it to return a classification and do not receive it for any other purpose.

Google API data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the app's access at any time at myaccount.google.com/permissions. Stored records can be deleted on request by the owner.
